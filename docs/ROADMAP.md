## How this is arranged

**One file per phase, under [`roadmap/`](./roadmap/).** This page is the index.

It was a single 112 KB file in 427 lines — the length is in the items, each of
which is a paragraph carrying what was decided and why. A phase is the unit the
plan is discussed in and the unit its items are grouped by, so it is the unit
the files use. No reference anywhere depended on a heading anchor.
