## Planned image generation around a time-shared host

The product direction is teaching materials, presentation illustrations and
general illustrations. Content stays internal by default; external services may
receive only approved content. Temporary suspension of some text services during
generation is accepted. That last requirement changes the September 7 survey's
recommendation to wait for another compute node.

The [construction plan](../plans/image-generation.md) records the accepted
requirements separately from proposed architecture and unresolved deployment
gates. It includes a source-backed baseline, cross-entrance admission and native
runtime dispatch, drain/release/restore state transitions, durable jobs, private
assets, accounting, API contracts, UI, and ordered delivery/acceptance slices.

The repository review used `main` at
`c890aa4546ec5e578d64b8144f8b166f06f9b0d0`, confirmed against the remote branch.
It found why an image adapter cannot be the first live change: embedding takes
no chat semaphore, retrieval runs before chat, Tier 2 calls a runtime separately,
and both admin entrances construct their own concurrency limiters. Blocking the
public chat route would leave several ways to reload text weights during image
execution. Model lifecycle and stale observations also need explicit reconciliation.

The plan corrects several earlier inferences without rewriting historical
measurements: remote nodes have no per-node runtime dispatch yet; gateway egress
is not universally denied; a separate image port need not duplicate the registry;
image work may have token usage; and binary delivery alone does not require MinIO.
September 7 memory occupancy and September 9's empty post-recovery runtime are
dated records, not current host telemetry.

**Documentation only.** No image feature, schema, runtime, service pause or external
provider integration was implemented or deployed. Hardware benchmarks, private
content, live database access and provider calls were not part of this review.
Implementation and live acceptance remain the work described by the plan.
