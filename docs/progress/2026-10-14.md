passages is a data-boundary change even with zero retention. Typed answers and
distribution-derived confidence do not prove correctness on research queries.
MPS support does not establish Mac Studio latency or safe co-residency, and a
checkpoint parameter count does not establish process memory. The current
model card and jeff README disagree on model size, so a future experiment must
pin and inspect the weights rather than treating a name as a fixed artifact.

The report defines held-out bilingual relevance comparisons, calibration and
abstention checks, version pins, latency/memory budgets and outage fallback as
reopening gates. These are proposed acceptance criteria. No cloud inference,
model download, production change or Mac Studio benchmark was performed.
