# 2026-10-18

## Residency mismatch and reconcile metrics (#50)

**Mismatch gauge.** #65 added `desired_resident`, so the availability observer
in the tailnet admin now publishes `nexus_model_residency_mismatch{alias}`.

- It is 1 for a model wanted resident but not shown resident by the evidence
  routing uses: a fresh positive Ollama observation, or intent for MLX.
- It is read in the same 30-second snapshot as capability availability, so a
  host with no traffic still reports it. It does not depend on the reconciler
  flag.

**Reconcile counter.** The reconciler counts every per-node pass in
`nexus_residency_reconcile_total{outcome}`.

**Alerts.** Two alerts join the Tier 1 mail path:

- the mismatch alert, after ten minutes;
- a give-up alert, immediately.

A new unit test ties the health job's alert-name filter to the rules file, so
a rule that is never mailed fails CI.

No deployment was made. The production Prometheus persistence check and the
live firing and recovery of `NexusCapabilityUnavailable` on 2026-10-17 are
recorded on #50.
